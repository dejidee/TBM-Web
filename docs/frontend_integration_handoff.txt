INTEGRATION FLOW

1. Upload the room

POST /api/v1/ai/upload-room
Content-Type: multipart/form-data

Form field:
file: <JPG, PNG or WEBP, maximum 10 MB>

Response:
{
  "success": true,
  "imageUrl": "https://res.cloudinary.com/.../room.jpg"
}

Always use this upload endpoint. Do not submit Google Images/cache URLs.

2. Create the project

Image:
POST /api/v1/ai/projects
Content-Type: application/json

{
  "sourceImageUrl": "<imageUrl from upload>",
  "outputType": 1,
  "prompt": "Transform this kitchen into a contemporary Nigerian luxury kitchen with warm natural stone, durable cabinetry and layered lighting.",
  "contextLabel": "Kitchen"
}

Video uses "outputType": 2.

Values:
1 = Image
2 = Video

Save the returned id; it becomes projectId.

3A. Generate an image

POST /api/v1/ai/generate/image
Content-Type: application/json

{
  "projectId": "<project id>",
  "sourceImageUrl": "<uploaded imageUrl>",
  "prompt": "Transform this kitchen into a refined contemporary Nigerian kitchen suitable for a Lagos home, using warm stone surfaces, practical premium cabinetry, layered lighting and locally appropriate finishes.",
  "style": "afro-minimalism",
  "contextTags": [
    "Kitchen design",
    "Renovation",
    "Cabinets",
    "Wood",
    "Tiles",
    "Natural stone"
  ]
}

3B. Generate a video

POST /api/v1/ai/generate/video
Content-Type: application/json

{
  "projectId": "<project id>",
  "sourceImageUrl": "<uploaded imageUrl>",
  "prompt": "Show this existing kitchen transforming into a refined contemporary Nigerian luxury kitchen with warm natural stone, premium cabinetry and layered lighting.",
  "style": "afro-minimalism",
  "durationSeconds": 5,
  "contextTags": [
    "Kitchen design",
    "Renovation",
    "Cabinets",
    "Wood",
    "Tiles",
    "Natural stone"
  ]
}

Use 5 seconds initially. The current model supports up to 15 seconds, but longer videos cost more and take longer.

CRITICAL AUTOMATIC-INVENTORY RULE

Do not send selectedProductIds and do not create a product-selection screen.

The backend automatically:
- Selects relevant in-stock Bogat SKUs.
- Retrieves their catalogue photos.
- Sends those references to the image model.
- Returns the selected products as matchedProducts.

matchedProducts is read-only result metadata. It must not become a pre-generation picker.

LOADING AND TIMEOUT HANDLING

- Image generation typically takes around 60–90 seconds.
- Video generation can take several minutes.
- Do not use a 60–100-second frontend timeout.
- Avoid Vercel serverless proxying for these requests.
- Prevent duplicate submissions while generation is running.
- Show a persistent “Generating your design” state.
- As a recovery fallback, poll:
  GET /api/v1/ai/projects

Project statuses:
1 = Pending
2 = Processing
3 = Completed
4 = Failed

When completed, render latestDesignUrl.

ERRORS

{
  "success": false,
  "message": "Human-readable error"
}

Handle:
400: invalid image/payload/project mismatch.
401: expired or missing access token.
403: subscription/quota failure.
429: rate limit.
500: provider/backend failure.

The UI should display message, never the entire raw error object.
